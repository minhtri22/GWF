# v0.8.2 Project Governance & Observable Agent Execution Protocol

v0.8.2 closes the next UAT gaps:

- rename project with immutable project_id and audit history;
- archive/drain/restore without deleting artifacts or logs;
- archived project read-only enforcement;
- Skill Registry with immutable SKILL.md revisions;
- persistent preflight, plan, checklist, QA and handoff;
- visible problem record before any retry/replan;
- AUTO and HUMAN_APPROVE recovery modes;
- live Phase Inspector status based on operational events;
- breathing UI signal for AI activity and attention states.

The UI intentionally shows plan/checklist/events/evidence/recovery decisions, not hidden model chain-of-thought.
