# v0.8 Research Product Alpha

v0.8 is the first operator-facing product slice of GWR.

The implementation deliberately keeps product UI as a projection of the runtime instead of making UI state authoritative. The backend API exposes a ProjectDashboardService read model; approval decisions still pass through authenticated governance; failure/recovery views are derived from persisted FailureRecord and RecoveryPlan state; and distributed execution remains owned by the v0.7 lease/effect contracts.

GitHub Pages hosts a static UAT console. It is useful for evaluating information architecture, dashboard readability, approval review flow, failure/recovery visualization and distributed execution visibility. Because GitHub Pages cannot run FastAPI, its approval buttons are local simulations and are labelled as such.

A production-hosted UI can replace the demo transport with the v0.8 product endpoints without changing the information model.
