# v0.8.1 Product Lifecycle & Process Inspector

This milestone adds the missing product lifecycle before UAT:

- create tenant-scoped Domain Package;
- add YAML revision;
- validate and publish immutable revision;
- create Project pinned to that revision;
- inspect current process, complete phase history and previous attempts;
- inspect one phase's run, inputs, outputs, evidence, gates, failure, checkpoint and chronological events.

GitHub Pages simulates lifecycle mutations locally because it is a static site. Live API behavior is separately tested against SQLite and PostgreSQL.

The project-domain pin is immutable. Upgrades require a later explicit governed upgrade flow; no project silently follows a newly published domain revision.
