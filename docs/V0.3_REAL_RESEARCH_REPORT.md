# GWR v0.3 — Real Research Alpha report

## Run
The v0.3 runtime executed one real bounded computational replication through the complete 17-phase research domain.

**Question:** on a precommitted small-sample binomial grid, is Wilson 95% coverage materially closer to nominal 0.95 than Wald coverage?

**Primary protocol:** n={10,20,40}; p=0.01..0.99 by 0.01; exact enumeration of Binomial(n,p), not Monte Carlo. PASS requires >=20% overall relative MAE reduction, lower Wilson MAE for each n, and secondary paired sign-test p<0.05.

## Prior work
The source cache is backed by live web retrieval of Brown, Cai & DasGupta (2001, 2002) and Agresti & Coull (1998). Those works already establish that Wald coverage can be poor and discuss/recommend alternatives including Wilson. Therefore the result below is explicitly a replication; no novelty is claimed for the statistical comparison.

## Executed recovery
Two operational failures were recorded and resolved:

1. `source_unavailable`: the Python process could not complete the outbound live literature request in the QA environment. The same phase retried with the provenance-stamped web snapshot.
2. `pilot_degenerate`: the initial three-point pilot grid violated the already-committed minimum of nine pilot points. Root was confirmed at `experiment_plan`; the runtime invalidated the affected subgraph, created a RecoveryPlan/checkpoint, resumed phase 06, expanded the pilot grid, and continued.

This produced lineage generation 1 rather than rewriting generation 0.

## Main result
The machine-produced analysis artifact reports:

- `all_n_improve = true`
- positive paired grid points: `230`
- negative: `30`
- ties: `37`
- relative MAE reduction: `0.8810606206638314` (~88.1%)
- exact two-sided sign-test p-value: `2.307106511082338e-39`
- protocol threshold: `0.20`
- outcome: **PASS**

The PASS is scoped to this fixed-grid coverage-error protocol. The sign test is secondary because the p-grid is a designed set, not a random population sample.

## Replication
A distinct grid (`n={15,30}`, `p=0.025..0.975`) was used for replay. Its direction was checked separately and stored in `replication_result`.

## Runtime evidence
The run completed with 21 phase executions (including retry/recovery), 58 checkpoints, 18 gate evaluations, 2 resolved failure records, 1 semantic RecoveryPlan, and 18 current artifacts. The authoritative evidence is `runtime.db`, `audit.json`, `status.json`, `artifacts.json`, and the SHA-256 manifest.

## Limitations
- Literature retrieval is alpha-grade: live HTTP plus a curated cache, not yet a Crossref/OpenAlex/Semantic Scholar production connector.
- The controlled alpha approver is an actor in the local run; it is not an authenticated human UI approval event.
- Statistical verification is independent code from the experiment aggregation path but runs in the same Python process/package.
- Only one real research domain example has been executed so far.
- Coverage accuracy is not the whole decision problem; interval expected length and alternative p weighting are open follow-ups.
